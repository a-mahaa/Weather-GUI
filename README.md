# Weather-GUI

Description:
This project is a weather application built with Python and a GUI interface. Users can enter a city name to view weather information such as temperature, humidity, and weather conditions using an API connection.

Language Used:
Python

Libraries Used:
Tkinter
Requests
Messagebox

Additional Files Required:
This project also requires a separate API Python file named "weatherAPI.py" to connect to the weather service and retrieve weather data.

Features:
- GUI desktop application
- Search weather by city
- Temperature display
- Humidity information
- Weather condition display
- API integration
- Error popup messages
